1.2 Data Value Distributions & Statistical Summary

  • Geographic Bounding Box: Latitude spans from 40.152481°N (southern Ávila/Salamanca) to 43.160687°N (northern León/Palencia/Burgos), with mean 41.750747° (SD 0.720572°). Longitude spans from -6.925360°W to -1.856444°W, with mean -4.531362° (SD 1.119373°).
  • Provincial Distribution (poblacion_provincia): Burgos (250 monuments), Valladolid (167), Soria (155), León (151), Palencia (149), Segovia (136), Salamanca (132), Ávila (121), and Zamora (116). One archaeological site (Castro de la Loma, ID 200849) lacks administrative location fields despite having valid coordinates (42.800344, -4.733072, located in Palencia).
  • Monument Types (tipoMonumento, 25 categories): Dominated by Iglesias y Ermitas (609; 44.2%), Castillos (173; 12.6%), Yacimientos arqueológicos (144; 10.4%), Palacios (109; 7.9%), and Monasterios (109; 7.9%).
  • Architectural Classifications (clasificacion, 10 categories): Arquitectura Religiosa (720), Arquitectura Civil (253), Yacimiento (144), Arquitectura Militar (33), Arquitectura Popular (12), Paraje Pintoresco (8), Conjunto Etnológico (8), Museo (3), Sitio Histórico (2), and Jardín Histórico (2).
  • Historical Periods (periodoHistorico, 40 unique combinations): Most frequent values are Edad Media (494), Edad Moderna (400), Edad Moderna,Edad Media (187), Romano (47), and Edad Contemporánea (39).

1.3 Data Quality Issues & Preprocessing Rules

Key Findings for RML/RDF Transformation:
  1. Duplicate Monument Identifiers (4 pairs): Identifiers 25157 (Monasterio Santa María Real de las Huelgas), 25171 (Monasterio de Santa Clara), 25211 (Palacio Real de la Granja de San Ildefonso), and 25212 (Palacio Real de Riofrío) appear twice because they belong to both Reales Sitios and Monasterios/Palacios. Mapping both rows to the same subject URI naturally merges their attributes and yields two mon:hasMonumentType triples.
  2. Multi-Valued Delimited Fields: periodoHistorico separates multiple periods with commas (e.g., "Edad Moderna,Edad Media"), while 8 records in identificadorBienInteresCultural separate multiple BIC codes with semicolons (e.g., "9598;9618" for Catedrales de Salamanca). These must be split into atomic values before generating triples.
  3. Missing Leading Zeros in Postal Codes: Because codigoPostal is stored numerically, codes for Ávila (05xxx) and Burgos (09xxx) appear as 4-digit integers (e.g., 5001, 9003). They must be left-padded with zeros to 5 characters ("05001", "09003") and typed as xsd:string. Two Burgos churches in Valpuesta (IDs 25443 and 25911) carry Álava border postal codes (01426 and 01424).
  4. HTML Markup & Entities in Descripcion: Descriptions contain <p align="justify"> tags and HTML character entities (e.g., &aacute;, &ntilde;, &nbsp;) that must be unescaped and stripped to clean UTF-8 text.

3. Resource Naming Strategy

Following W3C Cool URIs for the Semantic Web guidelines, our resource naming strategy uses HTTP URIs under a dedicated base domain, separating ontological terms (TBox) from instance data (ABox) and avoiding file extensions or implementation details in resource identifiers.

3.1 Base Domain & Namespace Structure

Component URI Pattern Strategy & Rationale
Base Domain http://www.monumentoscyl.es/ Clean, human-readable, domain-specific HTTP base URI independent of underlying server technology.
Ontology URI (TBox) http://www.monumentoscyl.es/ontology/monuments# (prefix mon:) Hash (#) URI pattern: Ideal for small-to-medium ontologies so that dereferencing any class or property retrieves the complete ontology schema in a single HTTP request.
Instances URI (ABox) http://www.monumentoscyl.es/resource/<type>/<id> Slash (/) URI pattern: Ideal for large datasets (1,374+ monuments and hundreds of geographical entities) so clients can dereference individual entities without downloading the entire dataset.

3.2 Ontology Term Naming Conventions (TBox)

  • Classes (owl:Class): Singular nouns written in UpperCamelCase (PascalCase), using English names for global interoperability alongside bilingual rdfs:label annotations (@en and @es): mon:Monument, mon:MonumentType, mon:Classification, mon:ConstructionType, mon:HistoricalPeriod, mon:Province, mon:Municipality, mon:Locality.
  • Object Properties (owl:ObjectProperty): Relational verb phrases written in lowerCamelCase: mon:hasMonumentType, mon:hasClassification, mon:hasConstructionType, mon:hasHistoricalPeriod, mon:locatedInLocality, mon:locatedInMunicipality, mon:locatedInProvince, mon:localityOf, mon:municipalityOf.
  • Datatype Properties (owl:DatatypeProperty): Attribute noun phrases written in lowerCamelCase: mon:identifier, mon:name, mon:bicIdentifier, mon:streetAddress, mon:postalCode, mon:description, mon:latitude, mon:longitude.
