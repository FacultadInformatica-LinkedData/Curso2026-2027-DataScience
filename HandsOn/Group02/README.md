## Proyecto: AirMove Madrid

Dominio: **medio ambiente (calidad del aire) + movilidad (tráfico rodado)** en la ciudad de Madrid.

Conjuntos de datos seleccionados (todos del portal de datos abiertos del Ayuntamiento de Madrid, https://datos.madrid.es):

1. Calidad del aire. Datos horarios desde 2001 (fichero de 2025-2026), CSV.
2. Calidad del aire. Estaciones de control (ubicación de las estaciones), CSV.
3. Tráfico. Histórico de datos del tráfico desde 2013 (septiembre de 2026, muestra), CSV.
4. Tráfico. Ubicación de los puntos de medida del tráfico (septiembre de 2026), CSV.
