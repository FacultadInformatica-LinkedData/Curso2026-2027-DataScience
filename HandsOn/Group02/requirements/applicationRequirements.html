Application Requirements - BiciMAD Explorer

Application Description

Our idea is to create a web application called BiciMAD Explorer. The application will help users find BiciMAD stations around Madrid and see information about them.

We want to make it easier for people to find bicycle stations and encourage the use of public bicycles.

Target Users

The application is designed for people living in Madrid, students, tourists and anyone who wants to use BiciMAD.

Main Features

Map of Stations

The application will show a map of Madrid with the location of the BiciMAD stations. Users will be able to click on a station to see more information.

Station Information

Each station will have a small information page showing its name, address, capacity and status.

Search

Users will be able to search for a station by its name, number or address.

Filters

Users will also be able to filter stations depending on their status. For example, they could choose to see only stations that are in service.

Data Used

The application will use the BiciMAD dataset from the Madrid Open Data Portal. We will mainly use these fields:

  • Name: station name.
  • number: station number.
  • Address: station address.
  • TotalBases: station capacity.
  • State: station status.
  • POINT_X and POINT_Y: station coordinates.

The CSV does not provide live information about the number of bicycles available at each station, so we will not include that feature.

Conclusion

With BiciMAD Explorer, we want to create a simple application that helps people find bicycle stations in Madrid and check their main information.
