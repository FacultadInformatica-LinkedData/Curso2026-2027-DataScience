Dataset Requirements - BiciMAD Explorer

Dataset Description

We have chosen a dataset about BiciMAD stations in Madrid. BiciMAD is the public bicycle-sharing service of the city. The dataset comes from the Madrid Open Data Portal.

The CSV contains information about the stations, such as their names, addresses, capacity, status and location. It has 631 records and 12 columns.

Dataset: BiciMAD Stations

Dataset Requirements

R1. Smart Cities

This dataset is related to Smart Cities because it contains information about public transport and sustainable mobility in Madrid.

R2. CSV Format

The dataset is available in CSV format. We have included the file bikestationbicimad_csv.csv in the csv folder of our project.

R3. Open License

The dataset is published by Madrid City Council through its Open Data Portal. The portal allows the reuse of its public data under its conditions of use, including acknowledging the source.

R4. Linking with Other Datasets

The dataset includes addresses and geographical coordinates. This information can be used to connect BiciMAD stations with other datasets about Madrid.

For example, we could link the stations with streets, neighborhoods or districts using their location.

R5. Documentation

The Madrid Open Data Portal provides information about the dataset and its contents.

R6. Multiple Data Sources

For now, we are only using one dataset. In the future, we could add another dataset about Madrid's districts or streets.

Possible Links with Other Datasets

Some fields that could be useful for linking data are:

  • Address: to connect stations with Madrid streets.
  • POINT_X and POINT_Y: to locate stations in districts or neighborhoods.
  • Name and number: to identify stations in other BiciMAD datasets.

Other datasets could contain information about streets, districts and neighborhoods in Madrid. These entities could be connected with our stations using their addresses or coordinates.

Conclusion

We think this dataset is a good choice for our project because it contains useful information about BiciMAD stations and their locations in Madrid.
