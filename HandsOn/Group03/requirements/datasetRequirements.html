REQUIREMENTS

R1. Data are in one of the selected smart city domains.

Los datos pertenecen al dominio de Smart Cities. Se tratan de bancos, de parques y zonas verdes. Todos los datasets son de https://datos.madrid.es/.

R2. Data are available as a CSV file.

Los datos están disponibles y descargables directamente en formato CSV desde el portal de datos abiertos.

R3. Data have an open license so they can be published.

Si, los datasets tienen la licencia Creative Commons Attribution 4.0 International (CC BY 4.0) que permite usar, compartir y modificar una obra libremente, siempre y cuando se dé crédito al autor original.

R4. Data can be easily linked with generic real-world entities (e.g., locations).

Los datasets incluyen coordenadas, paradas de metro cercanas, direcciones, etc.

R5. Documentation exists for the data (optional).

En la web de los datasets aparece una sección para descargar documentación que incluye el contenido y estructura del fichero
