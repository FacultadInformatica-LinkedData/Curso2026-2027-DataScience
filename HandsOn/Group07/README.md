## Proyecto: AirMove Madrid

Dominio: **medio ambiente (calidad del aire) y movilidad (tráfico)** en Madrid.

Conjuntos de datos seleccionados (todos del portal de datos abiertos del Ayuntamiento de Madrid, https://datos.madrid.es):

1. Calidad del aire. Datos horarios desde 2001, CSV.
2. Calidad del aire. Estaciones de control, CSV.
3. Tráfico. Histórico de datos del tráfico desde 2013, CSV.
4. Tráfico. Ubicación de los puntos de medida del tráfico, CSV.
